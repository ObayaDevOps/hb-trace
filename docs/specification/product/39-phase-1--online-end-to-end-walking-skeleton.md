# Phase 1 — Online end-to-end walking skeleton

Status: authoritative extracted specification; target behavior, not implementation evidence.
Source: [HB-TRACE-V1-PLAN.md — Phase 1 — Online end-to-end walking skeleton](../../../HB-TRACE-V1-PLAN.md#phase-1--online-end-to-end-walking-skeleton)

<a id="prd-39-01"></a>
<!-- requirement:PRD-39-01 -->
- Establish App Router/strict TypeScript, module dependency checks, Supabase Auth/RBAC, standard PostgreSQL
  migrations, audit events, jobs, provider adapters, CI and backup/export from the start.
<!-- /requirement:PRD-39-01 -->

<a id="prd-39-02"></a>
<!-- requirement:PRD-39-02 -->
- Deliver the installation stage: repair/link the manifest, supply correctly sized icons, choose the staff launch
  route, add installation guidance and test standalone sign-in/navigation over HTTPS. Present offline readiness
  accurately until the Phase 2 device preparation and storage checks are complete.
<!-- /requirement:PRD-39-02 -->

<a id="prd-39-03"></a>
<!-- requirement:PRD-39-03 -->
- Implement one complete online path: farmer/apiary → purchase/receipt → extraction → material lots/containers →
  moisture/release → packaging batch → immutable public publication revision.
<!-- /requirement:PRD-39-03 -->

<a id="prd-39-04"></a>
<!-- requirement:PRD-39-04 -->
- Add fixed-template import, direct backward/forward trace, basic stock/work queues and a synthetic recall drill.
<!-- /requirement:PRD-39-04 -->

<a id="prd-39-05"></a>
<!-- requirement:PRD-39-05 -->
- Test permissions, concurrent allocations, migration rollback/repair and public/private publication boundaries as
  part of the phase gate.
<!-- /requirement:PRD-39-05 -->
