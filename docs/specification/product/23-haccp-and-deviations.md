# HACCP and deviations

Status: authoritative extracted specification; target behavior, not implementation evidence.
Source: [HB-TRACE-V1-PLAN.md — HACCP and deviations](../../../HB-TRACE-V1-PLAN.md#haccp-and-deviations)

<a id="prd-23-01"></a>
<!-- requirement:PRD-23-01 -->
Represent HACCP controls as versioned records linked to process stages. For each control capture hazard,
critical/operational limit, monitoring method, frequency, responsible role, corrective action, verification and
required record. An out-of-limit result creates a deviation/non-conformance and requires documented disposition;
uploading a form alone never releases a batch.
<!-- /requirement:PRD-23-01 -->
