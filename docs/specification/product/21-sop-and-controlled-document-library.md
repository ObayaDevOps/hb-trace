<a id="prd-21-05"></a>
<!-- requirement:PRD-21-05 -->
Store approved PDFs as private controlled originals. Show title, code, version, owner, approver, effective date,
review date and required training. Only the current effective version is prominent to production staff; prior
versions remain read-only for audit. Publishing a revision records approval, supersedes the former version and
may request a staff read acknowledgement where required. V1 records acknowledgement but does not implement a
general training-management workflow. A read acknowledgement is not automatically proof of practical training or
competence.
