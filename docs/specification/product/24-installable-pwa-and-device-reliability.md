# Installable PWA and device reliability

Status: authoritative extracted specification; target behavior, not implementation evidence.
Source: [HB-TRACE-V1-PLAN.md — Installable PWA and device reliability](../../../HB-TRACE-V1-PLAN.md#installable-pwa-and-device-reliability)

<a id="prd-24-01"></a>
<!-- requirement:PRD-24-01 -->
**Accepted delivery decision — 2026-10-28:** V1 is an installable PWA. Home-screen installation, dependable offline
field work and operational notifications are separate deliverables. None changes the server's authority over
stock, payments, quality, publication or authorization. The mobile reference remains a design artifact; implement
the PWA against the operational application and its durable command services.
