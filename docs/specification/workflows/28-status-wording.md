<a id="wf-28-12"></a>
<!-- requirement:WF-28-12 -->
Server permissions apply to every staff read and write. **My work** shows the
officer's own activity; supervisor and quality queues use their appropriate
organization scope. Knowing a code does not grant access to private records.
