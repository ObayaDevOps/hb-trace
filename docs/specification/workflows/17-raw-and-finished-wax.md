# Raw and finished wax

Status: authoritative extracted specification; target behavior, not implementation evidence.
Source: [docs/mobile-first-workflow-ui-plan.md — Raw and finished wax](../../mobile-first-workflow-ui-plan.md#raw-and-finished-wax)

<a id="wf-17-01"></a>
<!-- requirement:WF-17-01 -->
1. Record extraction inputs, operator, facility and actual date/time. Separate honey,
   retained raw wax residue, waste and losses; review the quantity balance.
<!-- /requirement:WF-17-01 -->

<a id="wf-17-02"></a>
<!-- requirement:WF-17-02 -->
2. Weigh and label each raw-wax bucket, retain its extraction and source references,
   and record its storage location and independent quality status.
<!-- /requirement:WF-17-02 -->

<a id="wf-17-03"></a>
<!-- requirement:WF-17-03 -->
3. Select eligible raw-wax buckets and quantities. Allow partial use and multiple
   sources. Leave unused quantities in their original containers.
<!-- /requirement:WF-17-03 -->

<a id="wf-17-04"></a>
<!-- requirement:WF-17-04 -->
4. Record melting/filtering, operator, facility, actual time, recovered wax,
   separately retained material, waste and losses. Retained material has its own
   labelled output and storage location; it is not silently treated as waste.
<!-- /requirement:WF-17-04 -->

<a id="wf-17-05"></a>
<!-- requirement:WF-17-05 -->
5. Review the balance and create labelled finished-wax stock. Carry all source
   allocations into every output; show its location and applicable quality status.
<!-- /requirement:WF-17-05 -->

<a id="wf-17-06"></a>
<!-- requirement:WF-17-06 -->
Stock, container history and quality tracing cover both raw and finished wax.
General sales remain outside this revision; recall uses the minimal recipient register defined below. The reference demonstrates an
explicitly accounted balance; the server preserves V1 precision and reviewable
variance/tolerance policy, including explanations and authorized adjustments.
<!-- /requirement:WF-17-06 -->
