# Remaining operational settings

Status: authoritative extracted specification; target behavior, not implementation evidence.
Source: [docs/mobile-first-workflow-ui-plan.md — Remaining operational settings](../../mobile-first-workflow-ui-plan.md#remaining-operational-settings)

<a id="wf-32-01"></a>
<!-- requirement:WF-32-01 -->
The workflow decisions above are settled. The following details still need
owners and definitions before rollout:
<!-- /requirement:WF-32-01 -->

<a id="wf-32-02"></a>
<!-- requirement:WF-32-02 -->
1. The exact national identifier meant by “national insurance number”, its display
   label, purpose, access and retention. It remains optional for collection.
<!-- /requirement:WF-32-02 -->

<a id="wf-32-03"></a>
<!-- requirement:WF-32-03 -->
2. Approved material and receiving-grade choices; precision, currency, price
   rounding, payment, receipt/confirmation/dispute procedures and label format.
<!-- /requirement:WF-32-03 -->

<a id="wf-32-04"></a>
<!-- requirement:WF-32-04 -->
3. Stage-specific quality checks, evidence, applicable standards, limits and
   release criteria. The quality manager owns the review/problem workflow.
<!-- /requirement:WF-32-04 -->

<a id="wf-32-05"></a>
<!-- requirement:WF-32-05 -->
4. Public profile permissions, permitted map precision, withdrawal messaging,
   publication/distribution readiness and propagation to website caches.
<!-- /requirement:WF-32-05 -->

<a id="wf-32-06"></a>
<!-- requirement:WF-32-06 -->
5. Account provisioning/recovery, supported phones and languages, printer setup,
   offline/session/storage limits and the procedure for a lost device.
<!-- /requirement:WF-32-06 -->

<a id="wf-32-07"></a>
<!-- requirement:WF-32-07 -->
6. Customer website owner, integration endpoint/URL and operational support for
   unknown, withdrawn and unavailable public batches.
<!-- /requirement:WF-32-07 -->

<a id="wf-32-08"></a>
<!-- requirement:WF-32-08 -->
Record these settings in the appropriate V1 policy, schema and operational
sources as implementation proceeds.
<!-- /requirement:WF-32-08 -->
